## Review output

Use exactly this shape:

Verdict: PASS|REQUEST_CHANGES
Findings:
- [blocker|high] path[:line] — issue — why it matters
Required fixes:
- concise action

If there are no blocker/high issues:

Verdict: PASS
Findings:
- none
Required fixes:
- none
